MENÜPLANER – AKTUELLER STAND

Bereiche:
- Wochenplan
- Einkaufsliste
- Gerichte
- Snacks

Enthalten:
- Wochenplanung Freitag bis Donnerstag
- mehrere getrennt gespeicherte Wochen
- intelligente Zufallsauswahl
- Gerichte mit Zutaten
- mehrere Einkaufslisten; feste Liste „Essen“
- Zutatenübernahme mit zusammengeführten Quellen
- freie Mengennotizen
- Artikelvorschläge aus der Einkaufshistorie
- kompakte Druck-/PDF-Ausgabe
- Speicherung per localStorage

Lokal starten:
npm.cmd run dev

Im WLAN:
npm.cmd run dev -- --host 0.0.0.0

Produktionsprüfung:
npm.cmd run build

WICHTIG:
Die GitHub-Pages-Version und lokale Aufrufe verwenden getrennte localStorage-Daten. Es findet keine automatische Gerätesynchronisierung statt.
