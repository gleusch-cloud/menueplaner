MENÜPLANER – UPDATE

Einbau:
1. Vite-Server ggf. mit Strg+C stoppen.
2. Im Projektordner den Ordner "src" öffnen.
3. Die vorhandenen Dateien main.js und style.css durch die Dateien aus diesem ZIP ersetzen.
4. Danach wieder starten:
   npm.cmd run dev
   oder fürs Handy im WLAN:
   npm.cmd run dev -- --host 0.0.0.0
